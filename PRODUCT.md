# Oedipus Rex: A Search for Truth

## Platform

Web. Next.js App Router, TypeScript, CSS Modules, locally bundled literary content, static export. Backend and database integration are deferred.

## Users and purpose

Students studying Sophocles and a teacher reviewing a school project. The guide connects events, discoveries, characters, textual evidence, and interpretation. Accuracy and explanation account for 80% of the supplied rubric; creativity and interactivity account for 10% each.

## Approved commitments

The user approved the full seven-route plan and Greek literary exhibition identity in PLAN.md. That document governs palette, typography, content, illustrations, accessibility, and interactions. Preserve it rather than reopening the aesthetic direction. No invented personal student information or teacher submissions.

## Implementation boundary

Next.js installation and untouched starter verification precede custom interface work. Pages must remain readable before hydration; small Client Components add search, timeline comparison, quizzes, and optional browser persistence. No runtime APIs, accounts, or database dependencies.

## Evidence

PLAN.md is the approved specification. Literary content identifies the F. Storr edition and historical sources. Generated artwork is a modern interpretation. Design reference images inform composition; verified literary content replaces any mockup sample prose.
