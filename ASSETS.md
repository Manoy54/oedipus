# Artwork provenance

Created 11 November 2026, Asia/Manila. All images listed here were produced with the built-in `image_gen` tool in default built-in mode, not the CLI/API fallback. The figures and palace are modern interpretive illustrations for this project, not authenticated likenesses, archaeological reconstructions, museum photographs, or ancient objects. Credit them in the interface as **AI-generated modern illustrations, directed for this project**.

The source reference for the portrait family and palace is the generated Oedipus/Sphinx composition below. The project uses the supplied palette as art direction; rendered pigments/textures are illustrative and should not replace CSS color tokens.

Full figures, generous breathing room, no cropping. Wide 3:2 composition. Perfectly flat charcoal background #211E1B. Delicate ivory #F5F0E6 and dark bronze #70542B silhouettes with fine incised interior detail, subtle worn print texture within figures only. No photographic sculpture, no gradients, no text, no gore, no gold glow. This is a modern interpretation for an Oedipus Rex literary exhibition.

## Verification

Each selected output was opened for visual inspection before handoff. Character identity is interpretive, communicated through captions and varied posture rather than invented claims of authentic likeness. No image has text labels, a watermark, or graphic injury. Original generated PNGs are preserved in the Codex generated-image directory and in `design-references/assets-source/`. Optimized WebP delivery images are under `public/images/`.

The exact generation prompt is embedded in source PNG metadata. WebP assets have prompt sidecars created by Impeccable, whose embed tool uses a sidecar fallback for this format. Delivery images are resized/converted using sharp at quality 86, effort 6: character portraits and motifs are 640px square; hero and palace retain 1536px landscape width. Original PNGs remain available for future regeneration or export.


Delivery verification: 14 WebP images total 927,940 bytes; 14 original PNGs are preserved outside the public build under design-references/assets-source. Duplicate PNG copies were removed from public/images after SHA-256 comparison against the preserved originals. Final provenance scan: 14 rasters, zero missing prompts/sidecars.
